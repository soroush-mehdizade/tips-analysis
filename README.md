# 🧾 Tips Data Analysis

A descriptive and visual analysis of the **Tips dataset** — designed for beginners to learn how to perform **exploratory data analysis (EDA)** and create **meaningful visualizations**.  
This project helps newcomers understand how to summarize, interpret, and visualize real-world data using Python and Plotly inside a Jupyter Notebook.

---

## 📊 Project Overview

This project performs a **descriptive and graphical analysis** on the popular `Tips` dataset, which contains restaurant tipping information such as:
- Total bill amount  
- Tip amount  
- Gender and smoking status of the customer  
- Day of the week  
- Time of day (Lunch or Dinner)  
- Party size  

The main goal is to identify **patterns and relationships** between these variables and provide insights about tipping behavior.

---

## 🧠 Objectives

- Demonstrate the process of **exploratory data analysis (EDA)** in Python.  
- Visualize how factors such as **day of the week**, **time of day**, and **smoking habits** influence tips.  
- Help beginners become familiar with data analysis workflows using **Jupyter Notebook** and **Plotly**.

---

## 🧰 Tools & Libraries

- **Jupyter Notebook** — Interactive environment for code and visualization.  
- **Python 3.x** — Programming language used for analysis.  
- **pandas** — For data manipulation and descriptive statistics.  
- **Plotly** — For creating interactive and visually appealing plots.
